# Isometric redaction foundation

This change adds a browser-only utility that takes a rasterized image and explicit normalized rectangles, paints them opaque black in a fresh canvas, then makes the full JPEG and overlapping tiles only from that painted canvas. Rectangles are validated, expanded by two source pixels and rounded outwards. Invalid or absent masks fail closed. The original image is not modified, and the utility makes no network request.

This is a building block, not an approved cloud-export workflow. It does not automatically detect names, logos, embedded identifiers, metadata, text in repair JSON, or hidden information outside the selected rectangles. A local preview lets an engineer draw and inspect masks after OCR. It is not connected to the extraction endpoint; the preview does not transmit anything. The existing server-side prohibition on external model calls remains in place. User review, binding the reviewed result to the exact transmitted bytes, safe text handling, provider policy and end-to-end tests are still required before any external send. No claim of complete anonymization is made.

Tests cover rejected rectangles and a browser canvas with a synthetic sensitive patch crossing tile overlaps; the full view and each tile containing the patch are checked in both 2×2 and 3×3 grids; a real sample PDF is also opened through OCR and the local preview in the browser. Removing the paint step in an isolated copy made that browser test fail. The pixel test does not prove all JPEG edge effects or confidentiality of unknown drawings; real drawings and all output regions require review.
